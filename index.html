Introduction

Welcome to MadyOS — a project dedicated to creating fast, lightweight and optimized Windows builds. Modern Windows versions often include unnecessary background services, telemetry, pre‑installed apps and heavy components that slow down older hardware.

MadyOS solves this by offering optimized versions of Windows 10 and Windows 11, carefully stripped of bloat, compressed for faster installation, and tuned to run smoothly even on low‑end or aging PCs.

Alongside custom operating systems, this page also includes a curated list of optimized software and games, complete with a search bar to quickly find what you need.

Installation Error Fix

  1. Press Shift + F10 on the error screen.
  2. Type regedit and press Enter.
  3. Go to HKEY_LOCAL_MACHINE\SYSTEM\Setup\Status\ChildCompletion
  4. Open setup.exe and change value from 1 to 3.
  5. Restart installation.
